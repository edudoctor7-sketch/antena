> 그때 처음으로 연결됩니다.

## 두 가지 방법이 있습니다

| | ① 넷리파이 접수함 | ② 구글시트 (권장) |
|---|---|---|
| 설정 | **이미 해뒀습니다. 할 일 없음** | 아래 10분 작업 필요 |
| 후기가 남나요 | ✅ 넷리파이 화면에 쌓임 | ✅ 구글시트에 쌓임 |
| 후기가 홈페이지에 자동으로 뜨나요 | ❌ 직접 옮겨 적어야 함 | ✅ 「공개」에 O 만 넣으면 뜸 |
| 고친 글자가 다른 사람에게 반영되나요 | ❌ 안 됨 | ✅ 됨 |
| 한 달 접수 한도 | 100건(무료) | 사실상 없음 |

**①은 이미 넣어드렸으니 아무것도 안 하셔도 후기가 사라지지는 않습니다.**
다만 후기를 홈페이지에 띄우거나 글자 수정을 반영하려면 ②가 필요합니다.

### ① 넷리파이 접수함 확인하는 곳
1. https://app.netlify.com 로그인 (antena.kr 을 올린 계정)
2. `antena.kr` 사이트 선택 → 왼쪽 메뉴 **Forms**
3. **후기 / 강의문의** 두 개의 접수함이 보입니다
4. Forms → **Settings → Form notifications** 에서 메일 알림을 켤 수 있습니다

> 이 접수함은 **홈페이지를 새로 올린 뒤부터** 만들어집니다.
> (넷리파이가 올라온 파일을 보고 접수함을 만드는 방식이라 그렇습니다)

## ② 구글시트 연결 (10분, 한 번만)

컴퓨터로 하시는 게 편합니다.

### 1단계 · 구글시트 만들기
1. **김근안 대표님 구글 계정으로 로그인**한 상태에서 https://sheets.google.com 접속
2. **`+` 빈 스프레드시트** 클릭
3. 왼쪽 위 제목을 **`안테나랩 홈페이지`** 로 바꿉니다

### 2단계 · 스크립트 붙여넣기
1. 위쪽 메뉴 **확장 프로그램 → Apps Script** 클릭 (새 탭이 열립니다)
2. 화면 가운데 기존 내용(`function myFunction() { }`)을 **전부 지웁니다**
3. 같은 폴더의 **`Code.gs`** 파일을 메모장으로 열어 **전체 복사** 후 붙여넣기
4. 위쪽 **💾 저장** 클릭

### 3단계 · 웹앱으로 배포하기 (가장 중요)
1. 오른쪽 위 파란 **배포 → 새 배포**
2. **유형 선택** 옆 **⚙️ 톱니바퀴** → **웹 앱**
3. 아래처럼 맞춥니다
   - **다음 사용자로 실행: 나**
   - **액세스 권한이 있는 사용자: 모든 사용자** ← 이걸 꼭 바꿔야 합니다
4. **배포** 클릭
5. **권한 승인 → 계정 선택 →** "Google에서 확인하지 않은 앱" 이 나오면
   **고급 → (안전하지 않음) 이동 → 허용**
   (대표님이 직접 만든 스크립트라 안전합니다)
6. 마지막에 나오는 **웹 앱 URL** 을 복사합니다
   `https://script.google.com/macros/s/AKfyc....../exec` 모양입니다

### 4단계 · 홈페이지에 주소 넣기
1. 홈페이지 맨 아래 **[관리자]** → 비밀번호 **`5822`**
2. 왼쪽 **5번 「홈페이지에 올리기」**
3. **① 구글시트 연결** 칸에 주소를 붙여넣고 **[주소 저장]**
4. **[연결 확인]** → `연결됐습니다!` 가 뜨면 성공

### 5단계 · 확인
1. 홈페이지에서 **[후기 남기기]** 로 아무 후기나 하나 남깁니다
2. 구글시트 **「후기」** 탭에 한 줄이 생겼는지 봅니다
3. 그 줄의 **「공개」** 칸에 대문자 **`O`** 를 넣습니다
4. 홈페이지를 새로고침하면 그 후기가 화면에 보입니다

## 평소 사용법

**후기가 들어왔을 때** — 알림 메일이 옵니다. 구글시트 「후기」 탭을 열어
올리고 싶은 후기의 **「공개」 칸에 `O`**. 싫으면 비워 두면 됩니다.
「표시순서」에 1,2,3… 을 넣으면 그 순서대로, 홈페이지 메인에는 위에서 4개까지 보입니다.

**글자를 고쳤을 때** — 관리자 **1번 「글자 수정」** 에서 고치고 [저장하기] →
**5번 → ② [웹에 반영하기]**. 이제 다른 사람 화면에도 반영됩니다.

## 자주 막히는 곳

| 증상 | 해결 |
|---|---|
| 「연결 확인」 실패 | 3단계에서 **모든 사용자**로 안 했을 때가 대부분. 배포 → 배포 관리 → 연필에서 수정 |
| 주소를 넣었는데 안 됨 | 주소가 **`/exec`** 로 끝나야 합니다. `/dev` 는 안 됩니다 |
| 스크립트 고친 뒤 반영 안 됨 | **배포 → 배포 관리 → 연필 → 버전: 새 버전 → 배포** |
| 후기를 넣었는데 홈페이지에 안 보임 | 「공개」 칸에 `O` 를 넣으셨는지 확인 |
| 넷리파이 Forms 가 안 보임 | 고친 홈페이지 파일을 넷리파이에 다시 올려야 접수함이 생깁니다 |
