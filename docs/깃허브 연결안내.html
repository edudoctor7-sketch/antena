깃허브 연결하기

홈페이지 파일을 대표님 깃허브에 두고, 파일이 바뀌면 넷리파이가 알아서 홈페이지를 새로 올리도록 만듭니다.

약 15분 한 번만 하면 끝 컴퓨터로 하세요

왜 하나요

지금은 홈페이지 글씨 하나를 고쳐도 파일을 통째로 받아 넷리파이에 다시 올려야 합니다. 번거롭고, 잘못 올리면 되돌리기도 어렵습니다.

깃허브에 두면 파일 하나만 바꿔도 30초 뒤 홈페이지에 반영되고, 잘못됐을 때 예전 것으로 되돌리기도 쉽습니다.

도메인(antena.kr)과 지금 홈페이지는 그대로입니다. 넷리파이 계정도 대표님 것 그대로 쓰고, 후기 접수함도 유지됩니다. 주소가 바뀌거나 홈페이지가 잠시 멈추는 일은 없습니다.

준비물

시작하기 전에

① 깃허브(github.com) 로그인 — 대표님 계정
② 넷리파이(app.netlify.com) 로그인 — antena.kr 이 올라가 있는 대표님 계정
③ 카톡으로 받으신 「깃허브에_올릴_파일.zip」 — 압축을 미리 풀어 두세요

순서

네 단계입니다. 체크는 저장되니 중간에 쉬셨다가 이어서 하셔도 됩니다.

  1. 1

    저장소 만들기

    홈페이지 파일이 살 집을 하나 만듭니다.

    1. github.com 에 대표님 계정으로 로그인합니다.
    2. 오른쪽 위 ＋ → New repository 를 누릅니다.
    3. 아래처럼 채웁니다.
    Create a new repository
    Repository name
    antenalab-site
    공개 범위
    Private ← 비공개로 해주세요
    Initialize this repository with…
    아무것도 체크하지 않습니다 (README 포함 안 함)
    1. 맨 아래 Create repository 를 누릅니다.
  2. 2

    파일 올리기

    압축을 푼 폴더 안의 것들을 그대로 끌어다 놓습니다.

    1. 저장소 첫 화면의 uploading an existing file 글씨를 누릅니다.
      (안 보이면 Add file → Upload files)
    2. 압축을 푼 폴더를 열고, 그 안의 파일과 폴더를 전부 선택해 화면에 끌어다 놓습니다.
      폴더 자체가 아니라 안에 있는 것들을 올리셔야 합니다.
    3. 아래로 내려가 Commit changes 를 누릅니다.

    다 올리면 이런 모양이어야 합니다.

    antenalab-site

    📁 docs  — 설명서·구글시트 코드 (홈페이지엔 안 올라감)
    📁 site  — 홈페이지 본체 (index.html)
    📄 .gitignore
    📄 README.md  — 사용법 설명
    📄 netlify.toml  — 넷리파이에게 알려주는 설정

  3. 3

    넷리파이와 잇기핵심

    지금 쓰시는 홈페이지에 그대로 연결합니다. 새로 만드는 게 아닙니다.

    1. app.netlify.com 에 로그인하고 antena.kr 사이트를 누릅니다.
      새 사이트를 만들지 마세요. 지금 쓰고 있는 사이트를 골라야 도메인이 유지됩니다.
    2. 왼쪽 Site configuration → Build & deploy 로 들어갑니다.
    3. Continuous deployment 칸에서 Link repository 를 누릅니다.
    4. GitHub 를 고르고, 권한을 묻거든 허용한 뒤 antenalab-site 를 고릅니다.
    5. 설정 화면이 나오면 아래처럼 되어 있는지 봅니다.
    Build settings
    Branch to deploy
    main
    Build command
    비워 둡니다
    Publish directory
    site

    올려둔 netlify.toml 덕분에 Publish directory 가 자동으로 site 로 잡힐 수 있습니다. 그러면 그대로 두시면 됩니다.

    1. Deploy site (또는 Save) 를 누릅니다.
    2. Deploys 화면에서 초록색 Published 가 뜰 때까지 기다립니다. 보통 30초입니다.
    3. antena.kr 에 들어가 홈페이지가 평소처럼 잘 나오는지 확인합니다.
  4. 4

    제작자를 참여자로 넣기

    이걸 해두시면 앞으로 고칠 일이 있을 때 대표님이 아무것도 안 하셔도 됩니다.

    저장소는 대표님 것이고, 제작자에게 파일을 고칠 권한만 드리는 것입니다. 언제든 다시 빼실 수 있습니다.

    1. 저장소 화면 위쪽 Settings 를 누릅니다.
    2. 왼쪽 Collaborators → Add people.
    3. 제작자 깃허브 아이디 parkjiwoon-writer 를 넣고 초대합니다.

    이걸 건너뛰셔도 됩니다. 대신 고칠 때마다 파일을 받아 2단계처럼 직접 올리셔야 합니다.

이제부터는 이렇게 됩니다

고칠 일이 생기면 아래 흐름으로 저절로 반영됩니다.

1. 제작자가 깃허브의 파일을 고칩니다
2. 넷리파이가 그걸 보고 홈페이지를 새로 올립니다 (약 30초)
3. antena.kr 에 반영됩니다 — 대표님은 하실 일이 없습니다

홈페이지 글자·후기·사진을 직접 고치시는 것은 지금처럼 관리자 페이지(비밀번호 5822)에서 하시면 됩니다. 그건 깃허브와 상관없이 따로 돌아갑니다.

막혔을 때

이런 증상이렇게 하세요
연결했더니 홈페이지가 빈 화면이거나 「Page not found」 Publish directory 가 site 로 되어 있는지 확인해 주세요. 비어 있거나 다른 값이면 그렇습니다. Site configuration → Build & deploy 에서 고칠 수 있습니다.
저장소에 site 폴더가 안 보임 압축 푼 폴더 자체를 올리신 경우입니다. 올라간 것을 지우고, 폴더 안에 있는 것들을 다시 올려 주세요.
Deploys 에 Failed 가 뜸 Failed 를 눌러 기록을 보시고, 그 화면을 캡처해 제작자에게 보내주세요.
도메인이 사라질까 걱정됨 기존 사이트에 저장소를 잇는 것이라 도메인 설정은 건드리지 않습니다. 그래도 불안하시면 3단계 전에 Domain management 화면을 캡처해 두세요.
되돌리고 싶음 넷리파이 Deploys 에서 예전 배포를 고르고 Publish deploy 를 누르면 그때로 돌아갑니다.
