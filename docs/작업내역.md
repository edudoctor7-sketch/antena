## 2. 장애인 AI 교육 내용 추가

「하는 일 → 배움을 시스템으로 설계합니다」 안에 새 과정을 넣었습니다.

**장애인 AI 활용교육 · 일자리 연계** (4단계)
1. 낯설음 걷어내기 — 스마트폰·컴퓨터로 AI에 말 걸기, 질문하는 법
2. 일이 되는 도구로 — 문서·이미지·영상 만들기, 반복 업무 줄이기
3. 나의 결과물 만들기 — 각자 하나씩 완성해 포트폴리오로
4. **일자리로 잇기** — 기업 수요 확인, 직무 매칭, 채용 기업 사후 지원

같이 넣은 것: 주제 딱지 「AI 활용」, 아래 프로그램 칸에 「AI 활용⁠·⁠일자리」 카드.
→ **이 문구는 관리자 페이지에서 그대로 고칠 수 있습니다.** 대표님이 실제 운영 계획에 맞게 다듬으시면 됩니다.

## 3. 활동소식 칸 맞추기 · 글씨체

- 사진 크기가 제각각이어도 **칸은 항상 같은 크기(4:3)** 로 맞춰 보이게 했습니다.
  → PC에서 여섯 칸 모두 196×147로 동일, 옆 「컬러강점 진단」 칸과도 높이가 정확히 맞습니다(412px).
- 사진에 마우스를 올리면 살짝 확대되는 효과, 모서리 다듬기 추가
- 글씨체: 이미 좋은 글꼴(Pretendard)이 적용돼 있었는데, **쓰이지도 않으면서 로딩만 늦추던 Noto Sans KR을 걷어냈습니다.** 첫 화면이 더 빨리 뜹니다.

## 4. 관리자 페이지 — 「글자 수정」 기능 신설 ★

기존 관리자 페이지에는 **글자를 고치는 메뉴가 아예 없었습니다.** (후기·사진만 가능)
**1번 「글자 수정」** 메뉴를 새로 만들었습니다.

- 고칠 수 있는 칸 **36개** — 첫 화면, 숫자 세 칸, 소개글, 과정 4개(내용 목록 포함)
- **[[낱말]]** 처럼 대괄호 두 개로 감싸면 청록색 굵은 글씨가 됩니다
- 목록은 **한 줄에 하나씩**, 「제목 — 설명」으로 쓰면 앞부분이 굵게 나옵니다
- 화면의 문구 칸을 자동으로 읽어오는 방식이라, 나중에 칸이 늘어도 저절로 따라옵니다

## 5. 웹반영 · 후기 구글시트 저장 ★

### 지금까지의 문제
관리자 페이지에서 고친 내용이 **그 컴퓨터 브라우저에만** 저장돼서, 다른 사람 화면에는 반영되지 않았습니다.
후기도 메일로만 갔고 어디에도 쌓이지 않았습니다.

### 새로 만든 구조 — 구글시트를 창고로
```
방문자가 후기 남김  ─→ 구글시트「후기」탭에 한 줄 저장 + 대표님께 메일 알림
                        └→ 「공개」칸에 O 를 넣으면 홈페이지에 노출

관리자가 글자 고침  ─→ [웹에 반영하기] ─→ 구글시트「설정」탭에 저장
                                            └→ 모든 방문자 화면에 반영
```

**검증 완료**: 로컬 저장이 전혀 없는 새 방문자 화면에서도 시트에 저장된 문구와 후기가 그대로 나오는 것을 확인했습니다.

### 넷리파이 접수함도 같이 붙였습니다 (설정 불필요)
구글시트를 연결하기 **전에도 후기·문의가 사라지지 않도록**, 넷리파이 자체 접수함
(Netlify Forms)에 한 부씩 남게 해뒀습니다. 홈페이지를 다시 올리면 넷리파이 화면의
**Forms** 메뉴에 「후기」·「강의문의」 접수함이 생깁니다. 별도 설정은 없습니다.

다만 넷리파이 접수함은 **받아두기만** 합니다. 받은 후기를 홈페이지에 자동으로 띄우거나,
고친 글자를 다른 사람 화면에 반영하는 것은 구글시트 연결이 있어야 됩니다.
