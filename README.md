# 안테나랩 홈페이지 (antena.kr)

김근안 대표님 홈페이지. 넷리파이(Netlify)로 배포됩니다.

## 폴더

| 폴더 | 무엇 |
|---|---|
| `site/` | **인터넷에 올라가는 파일.** 지금은 `index.html` 하나입니다 |
| `docs/` | 설명서와 구글시트 코드. **인터넷에는 올라가지 않습니다** |

`netlify.toml` 에 `publish = "site"` 로 적혀 있어서, `docs/` 안의 내용은
주소를 알아도 웹에서 열리지 않습니다.

## 고칠 때

이 저장소의 **`site/index.html` 만 바꾸면** 넷리파이가 알아서 새로 올립니다.
따로 넷리파이에 들어가 파일을 끌어다 놓을 필요가 없습니다.

방법은 셋 중 편한 것으로:

1. **깃허브 화면에서 바로** — `site` 폴더 → `index.html` → 연필(✏️) → 고치고 **Commit changes**
2. **파일 통째로 교체** — `site` 폴더 → **Add file → Upload files** → 새 `index.html` 끌어다 놓기 → **Commit changes**
3. **명령어로** — `git add . && git commit -m "설명" && git push`

올린 뒤 **30초쯤** 지나면 antena.kr 에 반영됩니다.
반영이 됐는지는 넷리파이 **Deploys** 화면에서 초록색 **Published** 로 확인합니다.

## 되돌리기

잘못 올렸을 때는 깃허브 **Commits** 목록에서 예전 것을 찾아 되돌릴 수 있습니다.
넷리파이 **Deploys** 에서 예전 배포를 골라 **Publish deploy** 해도 됩니다.

## 홈페이지 관리 (대표님이 쓰시는 부분)

홈페이지 맨 아래 **[관리자]** → 비밀번호 **5822**

| 메뉴 | 하는 일 |
|---|---|
| 1 글자 수정 | 홈페이지 문구 고치기 |
| 2 후기 관리 | 메인에 보일 후기 정리 |
| 3 활동사진 | 사진 올리기·지우기 |
| 4 받은 문의·후기 | 새로 들어온 내용 |
| 5 홈페이지에 올리기 | 구글시트 연결 · **웹에 반영하기** |

글자를 고친 뒤에는 **5번 → ② 웹에 반영하기** 를 꼭 눌러야 다른 사람 화면에도 반영됩니다.
(이건 구글시트에 저장되는 것이라, 이 저장소를 건드리지 않습니다)

## 후기가 쌓이는 곳 두 군데

1. **구글시트** — 김근안 대표님 계정. 설정 방법은 `docs/구글시트 연결방법.md`
2. **넷리파이 Forms** — 설정 없이 자동. 넷리파이 사이트 → **Forms** 메뉴

## 참고

- 관리자 비밀번호(5822)는 `site/index.html` 안에 그대로 들어 있습니다.
  홈페이지 소스를 보면 누구나 알 수 있는 값이니, **중요한 자료를 지키는 자물쇠로 여기지 마세요.**
  실제로 구글시트에 저장할 때는 앱스스크립트 쪽에서 한 번 더 확인합니다.
- 비밀번호를 바꾸려면 `site/index.html` 의 `var PW` 와 `docs/Code.gs` 의 `var ADMIN_PW`
  **두 곳을 같은 번호로** 고쳐야 합니다.
